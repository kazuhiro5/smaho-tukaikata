## 希望する働き方・環境

```
企業規模の好み:
  ベンチャー〜中堅を優先。大手でも組織開発・HRコンサル等、現場に近い部署は可。
  やりがいと成長が両立できる規模感が理想。

勤務地の希望:
  首都圏（千葉・東京）。タイ単独旅行経験あり、海外視点も持つが国内優先。

職種の希望:
  提案型営業（コンサルティング営業）/ 教育サービス企画 / 組織開発支援 / HR企画。
  現場に近いBtoB支援が最も向いていると自己評価。
  純粋な事務・オペレーション専任職は避けたい。

リモートワーク:
  ハイブリッド希望。ただし成長フェーズでは対面も厭わない。

残業について:
  成長・経験量を重視するため一定の残業は許容。ただし威圧的な長時間労働は不可。
```

---

## NGワード・絶対に避けたいこと

```
- 威圧的・体育会系の社風（最重要NG）
- 同調圧力が強い組織・「みんな同じ」文化
- 心理的安全性が低い環境（本音を言えない職場）
- インターン給与・交通費なし（経験を搾取する姿勢の企業）
- 直近で大規模ハラスメント・不祥事が明らかな企業
- 人への関心が薄い・数字だけで人を評価する組織
```

## 将来の目標（3〜5年後のなりたい姿）

```
HR・教育領域での専門性を高め、将来的には人・組織に関わるソリューション提供者を目指す。

原体験から、組織や教育を通じてより多くの人を支援できる仕事をしたい。

中長期的には、不登校コミュニティ事業企画など自分の原体験を活かした
社会課題解決型のソリューションを自分でも手がけることが目標。
```

## インターンに求めるもの（優先度順）

```
1. BtoB提案・コンサルティングの実務経験（傾聴・ファシリテーション力を実際の業務で活かしたい）
2. 心理的安全性が高いチーム環境（本音で働ける・フィードバックがもらえる）
3. 組織・人事・教育領域に関わる業務内容（志望領域の実態理解）
4. 本採用への直結・または早期選考ルートへのアクセス
5. 報酬・交通費支給（長期インターンの場合は特に重視）
```

## 自己PRの核心（面接活用メモ）

```
核心メッセージ:
  「傾聴と自己開示で、相手が本音を話せる場をつくる人間」
  不登校経験→人間不信の克服→コミュニケーション力への投資という一貫したストーリー。

ガクチカの軸:
  通信制高校・早稲田塾での少人数環境での経験。
  新入生挨拶など人前に立つ行動。
  組織論（遠山ゼミ）を通じた「人と組織」への知的関心の深化。

ユニーク表現:
  「塩＝全体の味を邪魔せず、でも締まりを与える」→チームでの支え役・まとめ役を説明するエピソードとセット。

GPA対策:
  「GPA以外で得たもの」を具体化：
  - 自主学習（IT Passport対策、Claude活用）
  - 事業企画（不登校コミュニティ）
  - 語学・行動力（タイ単独旅行）
```
