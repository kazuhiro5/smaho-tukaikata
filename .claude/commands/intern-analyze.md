# インターン企業分析スキル

対象企業: **$ARGUMENTS**

あなたは企業分析の専門家（経営コンサルタント・就活アドバイザー）として、指定された企業をインターン志望者の視点で徹底分析してください。

## タスク手順

### Step 1: 情報収集（Web検索）
以下の情報をWeb検索で収集してください：
- 公式サイト、採用ページ、インターン募集要項
- 有価証券報告書・IR情報（上場企業の場合）
- OpenWork / 転職会議 / Glassdoor 等の社員口コミ
- 最新ニュース（直近1〜2年）
- 業界ポジション・競合他社情報

### Step 2: 分析を実施する
以下のすべての分析フレームワークを適用すること。

#### A. 企業概要サマリー（三点まとめ）
企業の本質を3つのキーポイントで表現する：
1. **何をしている会社か**（事業ドメイン・提供価値）
2. **どこが強い会社か**（差別化要因・競争優位性）
3. **どこに向かっている会社か**（中期戦略・将来性）

#### B. インターン情報サマリー（三点まとめ）
インターンシップの実態を3つのポイントで：
1. **何を学べるか**（業務内容・スキル習得機会）
2. **どんな人が向いているか**（求める人物像・カルチャーフィット）
3. **本採用への影響度**（直結型か経験型か・選考直結率）

#### C. SWOT分析
| 区分 | 内容 |
|------|------|
| **Strengths（強み）** | 内部の競争優位性 |
| **Weaknesses（弱み）** | 内部の改善余地 |
| **Opportunities（機会）** | 外部環境の追い風 |
| **Threats（脅威）** | 外部環境のリスク |

#### D. 組織・カルチャー分析
- **規模感**：従業員数・グループ全体の規模、部門構成
- **平均年齢・年収**：若手比率、給与水準（業界平均比）
- **社風・雰囲気**：トップダウン vs ボトムアップ、スピード感、多様性
- **働き方**：リモート可否、残業実態、フレックス制度
- **成長環境**：研修制度、異動機会、副業可否、社内公募

#### E. 財務・経営状況分析
- **売上高・営業利益・ROE**（直近3期のトレンド）
- **事業ポートフォリオ**：主力事業の依存度・新規事業への投資
- **財務健全性**：自己資本比率、有利子負債
- **成長ドライバー**：何で稼いでいて、何が伸びているか

#### F. 業界・競合ポジション（Porter's Five Forces）
1. **競合との競争**：主要競合との差別化
2. **新規参入の脅威**：参入障壁の高低
3. **代替品の脅威**：代替テクノロジー・サービスのリスク
4. **買い手の交渉力**：顧客依存度
5. **売り手の交渉力**：仕入・パートナー依存度

#### G. インターン志望者向け総合評価
以下を5段階（★1〜5）で評価し、理由を添えること：
- **事業の将来性** ★★★★☆
- **成長環境・学習機会** ★★★★☆
- **働きやすさ** ★★★☆☆
- **本採用への直結度** ★★★★☆
- **社会的インパクト** ★★★☆☆

### Step 3: 分析結果をファイルに保存する

以下のパスに分析結果をMarkdownファイルとして保存してください：
`internship-analyses/<企業名>_分析.md`

ファイルには以下のヘッダーを必ず含めること：
```
# [企業名] インターン志望企業分析レポート
作成日: [今日の日付]
ステータス: 承認待ち
```

### Step 4: 承認リストを更新する

`internship-analyses/承認リスト.md` に以下の形式でエントリーを追加（ファイルが存在しない場合は新規作成）：

```markdown
| 企業名 | 分析日 | 総合評価 | ステータス | 詳細リンク |
|--------|--------|----------|------------|------------|
| [企業名] | [日付] | ★★★☆☆ | 承認待ち | [企業名]_分析.md |
```

### Step 5: 分析完了の報告

分析が完了したら以下を報告してください：
1. 分析で最も重要だと判断した発見（Top 3）
2. インターン応募を**推奨する理由** または **慎重になるべき理由**
3. もし応募するなら、面接・ESで使える**企業研究ポイント3つ**

---

## 注意事項
- すべての分析は**客観的根拠**（数値・出典）を示すこと
- 情報が取得できない場合は「情報なし（要確認）」と明記すること
- 憶測や推測で事実のように書かないこと
- 批判的な観点も含め、バランスの取れた分析を行うこと
